# Scholarship Monitoring System
1. Create a Supabase project. Run `schema.sql` in the SQL Editor.
2. Authentication > Providers > Email: turn off "Confirm email" for the lab.
3. Put your Project URL and anon key in `config.js`.
4. Push to GitHub, then Settings > Pages > Deploy from branch `main` / root.
5. Open the site, click "Create scholar account", then run the admin `update profiles ...` line at the bottom of `schema.sql`.
Commits: `Initialize scholarship monitoring system` > `Create scholar and scholarship database modules` > `Implement grade submission and verification` > `Add compliance evaluation dashboard and deployment`
